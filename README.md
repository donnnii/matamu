# MATAMU

MATAMU = MApping Alamat Tanpa MUmet 😆

Merupakan aplikasi otomatisasi untuk mengubah alamat menjadi koordinat (Geocoding) dengan memanfaatkan data dari Google Map.
Menggunakan selenium sebagai alternatif dari Geocoding API yang memiliki limit untuk versi gratis (10.000 request per bulan)

Dengan tools ini request dapat dilakukan dengan tidak ada batasan.

APlikasi ini bertindak sebagai API untuk diintegrasikan dengan n8n
